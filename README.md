# TASK1# Vulnerability Assessment Report

A professional web application vulnerability assessment covering identification, risk classification, business-language explanation, and remediation steps.

## Contents
- `VULNERABILITY_ASSESSMENT_REPORT.md`: Full assessment report
- `README.md`: Project overview

## Tools
- Nmap
- OWASP ZAP (Passive Scan)
- Browser DevTools
- Canva (report design)

## Skills Demonstrated
- Vulnerability analysis
- Risk classification (Low / Medium / High)
- Security reporting
- Client communication

## Target
OWASP Juice Shop, a deliberately vulnerable application used for security training. Run locally with:
```bash
docker run -p 3000:3000 bkimminich/juice-shop
```

This project is for educational purposes. Only test systems you have explicit permission to assess.
